# ♟️ Chess Game Engine

A modular and extensible **Chess Game Engine** designed to handle chess rules, board state, piece movement, move validation, and game logic.

The project focuses on building the core logic behind a chess game while keeping the codebase organized and easy to understand, extend, and integrate with a user interface.

---

## 📌 Project Overview

**Chess Game Engine** is a logic-focused chess project that provides the foundation required to build a complete chess application.

The engine is responsible for managing:

- ♟️ Chess board state
- ♜ Piece movement
- ✅ Legal move validation
- 👑 King safety
- ⚔️ Captures
- ♟️ Pawn movement and promotion
- 🔄 Turn management
- 🏁 Game-state detection
- 🧩 Modular chess logic

The project is designed with future expansion in mind, allowing a graphical interface, multiplayer system, AI opponent, puzzles, and other features to be integrated later.

---

## ✨ Features

### ♟️ Chess Logic

- Complete chessboard representation
- Individual piece movement rules
- Legal move validation
- Capture handling
- Turn management
- Board-state management

### 👑 Game Rules

- Check detection
- Checkmate detection
- Stalemate detection
- Castling support
- En passant handling
- Pawn promotion
- King-safety validation

### 🧩 Architecture

- Modular game-engine structure
- Separation of chess rules and game state
- Reusable components
- Easy to extend
- Suitable as a backend/core layer for a chess application
